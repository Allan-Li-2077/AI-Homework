# Hello World 示例Skill

这是一个简单的示例Skill，用于验证Harness的渐进式加载执行流程。

## 触发场景

当用户说出类似下面的话时触发本 skill：
- "hello"
- "你好"
- "测试一下"
- "test"
- "demo"
- "运行示例"

## 执行流程

1. **接收输入**：记录用户输入的内容，用于演示。

2. **加载资源**：加载SKILL.md和相关资源文件，展示渐进式加载过程。

3. **生成响应**：根据用户输入生成一条友好的响应消息。

4. **保存结果**：将执行结果保存到outputs目录。

5. **展示完成**：告知用户执行已完成。

## 注意事项

- 这是一个演示Skill，用于验证Harness功能。
- 所有步骤都是模拟的，不依赖外部服务。
