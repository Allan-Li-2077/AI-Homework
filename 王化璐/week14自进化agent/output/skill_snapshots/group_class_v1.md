## 预约规则
- 团课提前3天开放预约
- 每人每节课限约1个名额
- 预约后需在课程开始前15分钟签到
- 体验卡不可预约团课

## 取消规则
- 课程开始前2小时可取消
- 2小时内取消视为爽约
- 爽约3次禁约1周

## 特殊团课
- 瑜伽/普拉提：需自带瑜伽垫或租用5元/次
- 搏击操：需自备拳击手套或租用10元/次
- 游泳课：需佩戴泳帽泳镜，限会游泳者参加
