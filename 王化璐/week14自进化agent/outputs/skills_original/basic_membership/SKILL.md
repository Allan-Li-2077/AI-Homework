## 会员卡类型
- 年卡：不限次入场，有效期365天
- 季卡：限30次入场，有效期90天
- 月卡：限12次入场，有效期30天
- 体验卡：限1次入场，有效期7天

## 入场规则
- 营业时间：6:00-23:00
- 每次入场需刷卡，单次时长不超过3小时
- 储物柜日租5元，离场需清空

## 附加权益
- 年卡会员：赠送2次体测、免费饮水
- 季卡会员：赠送1次体测
- 所有会员：免费使用淋浴、停车场（限2小时）
