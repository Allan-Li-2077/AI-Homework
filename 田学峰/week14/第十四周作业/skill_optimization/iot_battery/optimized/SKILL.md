# IoT电池设备运维

## 电池类型选型

| 类型 | 电压 | 工作温度 | 自放电/年 | 可充 | 典型场景 |
|------|------|---------|----------|------|---------|
| Li-SOCl2(锂亚) | 3.6V | -55~+85℃ | <1% | 否 | 远程传感器/水气表，5年+长寿命 |
| Li-MnO2(锂锰) | 3.0V | -20~+60℃ | 2-3% | 否 | 低成本短期监测 |
| Li-ion(锂离子) | 3.7V | -20~+60℃ | - | 是(500-1000次) | 太阳能节点，有能量收集 |
| Li-Po(锂聚合物) | 3.7V | -20~+60℃ | - | 是 | 薄形/特殊形状设备 |
| 超级电容 | - | - | - | 是(百万次+) | 瞬间大电流/辅助储能 |

**选型决策**：功耗<100µA且需5年+→Li-SOCl2；功耗>1mA→可充电+能量收集；极低温-40℃以下→Li-SOCl2；成本优先→Li-MnO2。

## 功耗管理

### 低功耗策略
- **睡眠模式**：Stop(µA~数十µA)、Standby(~1µA，唤醒慢)，按需选择
- **唤醒频率**：温度监测30min/次、震动5min/次；数据无变化可延长间隔
- **传输优化**：LoRa/NB-IoT优于WiFi/蓝牙；采用压缩/聚合/差分传输减少数据量
- **传感器**：选低功耗型号，不测量时断电或进低功耗模式

### 功耗评估
- **平均功耗**：`(活跃功耗×活跃时间 + 睡眠功耗×睡眠时间) / 总周期`
- **寿命估算**：`寿命(h) = 电池容量(mAh) / 平均功耗(mA)`
- 例：2400mAh / 0.088mA ≈ 27273h ≈ 3.1年（未计自放电/温度影响，实际更短）
- **峰值功耗**：影响电压跌落，低温下尤其需确保电池可承受，否则设备复位/丢数据

## 充电与能量收集

### 太阳能
- 板功率 ≥ 平均功耗的**3-5倍**（应对阴雨/冬季）
- 控制器：MPPT(效率95-99%,贵) 或 PWM(70-80%,便宜)
- 储能：**LiFePO4**（循环2000次+，安全耐高温），容量需支撑**≥7天**连续阴雨

### 其他收集方式
| 方式 | 功率级 | 适用场景 |
|------|--------|---------|
| 压电 | µW | 振动源附近的设备 |
| 热电(塞贝克) | mW | 稳定温差（工业管道等） |
| 射频 | nW~µW | 近基站/路由器 |

## 故障诊断

### 常见故障速查

| 故障 | 可能原因 | 处理 |
|------|---------|------|
| 电压突降 | 老化/内短路/功耗异常增大/低温 | 查异常行为→查温度→换电池测试 |
| 寿命不达预期 | 实际功耗超标/自放电异常/高温老化/漏电流 | 功耗分析测实际值→查电池质量→优化策略 |
| 鼓包/漏液 | 过充/过放/高温 | **立即停用**→查充电电路/工作温度→换电池+改善散热 |
| 充不进电 | 充电电路故障/过放保护/内阻增大/充电器功率不足 | 查输出电压电流→小电流预充激活→仍不行则更换 |

### 诊断流程
1. **确认告警**：核实类型/时间/位置
2. **远程诊断**：拉取电压/温度/信号/唤醒次数
3. **现场排查**：电池外观/接线/安装环境
4. **故障处理**：换电池/调参数/改善环境
5. **记录归档**：现象→诊断→措施→结果

## 寿命预测与BMS

### 预测方法
| 方法 | 原理 | 精度 | 成本 |
|------|------|------|------|
| 电压监测 | 电压接近截止电压即将耗尽 | 低 | 低 |
| 库仑计数 | 累计放电量算剩余容量 | 高 | 中（需电流检测+库仑芯片） |
| 阻抗测量 | 内阻随老化增大 | 高 | 高（需阻抗测量电路） |

### BMS保护阈值
- **过压**：Li-ion充电截止 **4.2V±0.05V**
- **欠压**：Li-ion放电截止 **2.5~2.75V**
- **过流**：超阈值切断放电
- **温度**：充电0~+45℃，放电-20~+60℃
- **均衡**：串联电池组需均衡各节电压

## 安全规范

### 存储
- 环境：干燥阴凉通风，10~25℃，湿度<65%，避光避金属
- 期限：一次性锂电池5-10年，可充锂电池3-5年；电压<额定80%需更换

### 运输
- 锂电池=第9类危险品，需UN标准包装+标签
- 空运严格限制，查IATA《危险品规则》

### 使用禁忌
- **严禁**拆解/改装/挤压/短路/投入火中
- 防水防潮（尤其接线端子）
- 废旧电池→有害垃圾→指定回收点

### 紧急处理
| 情况 | 处理 |
|------|------|
| 起火 | 干粉灭火器/沙子（**勿用水**），疏散+报消防，防有毒气体 |
| 漏液 | 戴手套护目镜→干布清理→密封袋封装；接触皮肤立即大量清水冲洗 |
| 鼓包 | 立即停用，停止充放电，密封袋封装后按废旧处理 |
