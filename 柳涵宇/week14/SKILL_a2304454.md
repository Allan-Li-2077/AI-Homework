# 日志分析器(Log Analyzer)

## 快速开始

```bash
python3 {skill_dir}/scripts/analyze_logs.py 文件 [--format auto|nginx|apache|json|app] [--top N] [--grep 子串] [--limit N]
```

以流式方式读取文件(内存占用 O(1)),输出单个 JSON 报告:`lines_total`(总行数)、`lines_parsed`(解析成功数)、`parse_errors`、`time_range`(时间范围)、状态码/级别分布、`top_paths`(热点路径)、`top_ips`(热点 IP)、`peak_minutes`(每分钟峰值)、`avg_bytes`(平均字节数)、未解析行的样例。

## 工作流程

1. 用 `-format auto`(默认)运行脚本。
2. 若 `parse_errors` 超过约 5%,说明格式不匹配:自行读取文件前约 20 行,然后要么强制指定 `--format`,要么参考 [references/custom-formats.md](references/custom-formats.md) 处理不支持的格式(IIS W3C、syslog 等)。
3. 依据 JSON 结果回答用户问题。引用确切数字;top-N 结果使用小型 markdown 表格。
4. 超大文件:先用 `--grep '子串'` 缩小范围,或用 `--limit N` 只扫描开头部分,再决定是否全量扫描。

## 注意事项

- 查看原始行/特定行:直接使用 Read/Grep 工具,不要用本脚本。
- JSON 日志:字段名各异(`ts`/`time`/`@timestamp`、`level`/`severity`)——脚本会自动探测常见变体;通过 `parse_errors` 确认是否识别成功。
- 统计路径时会去掉查询字符串;如果这对用户有影响,请说明。
