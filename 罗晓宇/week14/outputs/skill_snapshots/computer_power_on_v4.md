## 电脑启动问题
### 问题描述
电脑无法开机

### 解决方案
1. 检查电源是否正常连接，确保电源插头插紧；
2. 检查指示灯是否正常亮起，如果没有，可能是电源问题，需要更换电源；
3. 如果按下开机键后指示灯有反应但没有启动显示，可能是进入安全模式/紧急模式，可尝试：
   - 关机拔掉电源再按开机键放电；
   - 拔下内存条用纸巾或橡皮擦拭；
   - 拔下主板电池再放回去；
4. 电源故障的表现：按下开机键无反应，没有风扇转动的声音，可能是电源出现问题，需要更换电源；


## 电脑启动后无显示问题
### 问题描述
电脑启动后显示器无显示

### 解决方案
1. 检查显示器右下角指示灯是否亮起，没有的话按下开关检查是否正常显示；
2. 如果显示器亮起但无输入，可以尝试重启电脑或注销账户，优先推荐重启电脑；
3. 如果按下显示器开关键无反应，检查显示器电源线是否插好和数据线是否损坏；
4. 如果电源线和数据线没问题，可以将数据线从主机上的显卡插口换到核显插口，如果有显示说明显卡出现问题；
