## 文件保存位置
### 问题描述
机房电脑重启后系统文件复原，作业应保存在哪个盘

### 解决方案
1. 机房电脑重启后系统文件全部复原，一般会留一个非复原盘以备使用；
2. 上课写作业请把作业保存在 D 盘或者 E 盘，以免意外关机后文件丢失；
3. 不要保存在 C 盘，因为 C 盘是系统盘，重启后会被复原。

## 课后文件清理
### 问题描述
下课后作业没有及时拷贝走的风险

### 解决方案
1. 下课时要把作业拷贝走；
2. 否则如果课后进行了机房维护部署，非复原盘文件也会被清理掉。
