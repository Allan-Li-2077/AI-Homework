## 一、Mixtral 8x7B (Mixture of Experts)

### 模型概述
- **发布机构**: Mistral AI
- **发布时间**: 2023年12月
- **参数规模**: 46.7B总参数，每次推理激活12.9B参数

### 核心结构特点

#### 1. 稀疏混合专家架构 (Sparse Mixture of Experts, SMoE)
```
输入 → Router → 选择2个Expert → 加权输出 → 下一层
         ↓
    8个Expert并行
    (每次只激活2个)
```

#### 2. 关键技术创新
- **动态路由机制**: 每个token通过路由网络选择最合适的2个专家
- **负载均衡**: 确保各专家均匀使用，避免专家退化
- **稀疏激活**: 虽有46.7B参数，但每次只用12.9B，效率极高

#### 3. 架构参数
- 层数: 32层
- 注意力头: 32个
- 上下文长度: 32K tokens
- 词表大小: 32K

### 优势与特点
1. **效率**: 推理速度接近13B模型，但性能媲美70B模型
2. **成本**: 计算成本远低于同等性能的密集模型
3. **可扩展性**: 易于横向扩展专家数量

## 二、Qwen (通义千问)

### 模型概述
- **发布机构**: 阿里巴巴达摩院
- **系列**: Qwen-7B, Qwen-14B, Qwen-72B, Qwen-1.5, Qwen-2
- **特色**: 面向中文优化的多语言大模型

### 核心结构特点

#### 1. 改进的Transformer架构
```
Embedding → RMSNorm → 多头注意力 (GQA) → FFN → RMSNorm → Output
              ↓                           ↓
           SwiGLU激活              旋转位置编码(RoPE)
```

#### 2. 技术亮点
- **GQA (Grouped Query Attention)**: 减少KV cache，提升推理效率
- **SwiGLU**: 替代传统ReLU，提升非线性表达能力
- **RoPE**: 更好的位置编码，支持长文本外推
- **RMSNorm**: 替代LayerNorm，训练更稳定

#### 3. 训练优化
- **多阶段训练**:
  1. 预训练: 3T+ tokens，中英文比例约3:7
  2. 后训练: SFT + RLHF + DPO
  3. 长文本适配: 32K → 128K扩展

#### 4. 特色功能
- **工具调用**: 原生支持function calling
- **代码能力**: 专门的Code-Qwen变体
- **多模态**: Qwen-VL视觉语言模型

### 中文优化策略
1. 中文词表扩充至150K+
2. 中文语料占比高
3. 针对中文任务微调

## 三、DeepSeek-V2

### 模型概述
- **发布机构**: 深度求索(DeepSeek)
- **发布时间**: 2024年5月
- **参数规模**: 236B总参数，21B激活参数

### 核心结构特点

#### 1. MLA (Multi-head Latent Attention)
```
传统注意力: Q, K, V 三个独立矩阵 → 内存占用大
     ↓
MLA: 共享低秩压缩 → KV cache减少93.3%
```

**技术细节**:
- K、V向量通过共享的低秩投影压缩
- 推理时KV cache从10.4GB降至0.7GB
- 不损失模型能力

#### 2. DeepSeekMoE架构
```
每层结构:
- 共享专家: 2个 (每次必选)
- 路由专家: 160个 (选择6个)
- 总激活: 21B参数
```

**创新点**:
- **共享专家**: 确保基础能力
- **细粒度专家**: 更精细的专业化
- **负载均衡**: 避免专家崩溃

#### 3. 训练效率
- 使用自研框架HAI-LLM
- FP8混合精度训练
- 训练成本仅为同规模模型的1/10

### 性能特点
1. **推理高效**: 激活参数仅21B，速度快
2. **能力强大**: 多项基准测试超越Mixtral和GPT-4
3. **经济性**: 训练和推理成本都极低

## 四、ChatGLM 系列

### 模型概述
- **发布机构**: 智谱AI
- **系列**: ChatGLM-6B → ChatGLM2-6B → ChatGLM3-6B → GLM-4
- **特色**: 中文对话优化

### 核心结构特点

#### 1. GLM (General Language Model) 基础架构
```
自回归空白填充:
[Part A] [MASK] [Part B]
    ↓
通过双向注意力预测MASK部分
```

#### 2. 位置编码创新
- **2D位置编码**:
  - Position 1: 文档内位置
  - Position 2: 生成序列位置
- 支持任意长度外推

#### 3. ChatGLM3的三种模式
```
1. Base模式: 标准续写
2. Chat模式: 多轮对话
3. Code模式: 代码补全
```

#### 4. 多模态扩展 (GLM-4V)
- 图像编码器: EVA-CLIP
- 视觉-语言对齐层
- 统一的多模态理解

### 技术特色
1. **中文优化**: 中文词表和训练数据
2. **长文本**: 支持128K上下文
3. **工具调用**: 原生支持function calling
4. **推理优化**: INT4量化，支持低配GPU

## 五、Yi 系列

### 模型概述
- **发布机构**: 零一万物
- **系列**: Yi-6B, Yi-34B, Yi-VL
- **特点**: 性能优异的基座模型

### 核心结构特点

#### 1. 架构设计
- 标准Transformer + 多项改进
- GQA: 提升推理效率
- SwiGLU: 激活函数
- RoPE: 位置编码

#### 2. 训练特色
**超长上下文训练**:
- Yi-6B/34B: 4K → 200K渐进式扩展
- 使用position interpolation技术
- 支持长文档理解

**高质量数据**:
- 3.1T tokens
- 中英文混合
- 多轮数据清洗

#### 3. Yi-VL多模态
```
视觉编码器(CLIP) → 投影层 → LLM解码器
         ↓
    图像patches
         ↓
    视觉tokens
```

### 性能亮点
1. **基准测试**: 多项评测超越Llama-2
2. **指令遵循**: SFT后对话能力强
3. **代码能力**: Yi-Coder专注编程任务

## 六、Falcon 系列

### 模型概述
- **发布机构**: 阿联酋技术创新研究所(TII)
- **系列**: Falcon-7B, Falcon-40B, Falcon-180B
- **特点**: 开源且商用友好

### 核心结构特点

#### 1. 多查询注意力 (Multi-Query Attention, MQA)
```
传统: Q(n heads), K(n heads), V(n heads)
         ↓
MQA: Q(n heads), K(1 head), V(1 head)
         ↓
KV cache减少96%，推理速度提升5倍
```

#### 2. RefinedWeb数据集
- **规模**: 5T tokens的网页数据
- **质量**: 严格的清洗流程
  1. URL过滤
  2. 内容去重
  3. 质量评分
  4. 多语言过滤

#### 3. FlashAttention优化
- 使用FlashAttention-2加速训练
- 减少内存占用
- 支持更长的序列

### 训练配置
- Falcon-180B:
  - 3.5T tokens训练
  - 4096 A100 GPU
  - 训练时间: 约2个月

## 七、结构对比总结

### 1. 效率优化方向

| 模型 | 主要技术 | 效率提升 |
|------|---------|---------|
| Mixtral | MoE稀疏激活 | 推理成本降低70% |
| DeepSeek-V2 | MLA + MoE | KV cache降低93% |
| Falcon | MQA | 推理速度提升5倍 |
| Qwen | GQA | KV cache降低50% |

### 2. 中文能力对比

| 模型 | 中文优化 | 典型应用 |
|------|----------|---------|
| Qwen | 中文词表150K+ | 通用对话、工具调用 |
| ChatGLM | 双语训练 | 对话、代码 |
| Yi | 中英混合 | 长文档、多模态 |

### 3. 架构创新对比

```
传统Dense模型:
所有参数每次都激活 → 计算量大但能力强

MoE模型(Mixtral, DeepSeek):
稀疏激活 → 同等推理成本下能力更强

注意力优化(Falcon, Qwen):
减少KV cache → 长文本推理更高效

多模态扩展(Yi-VL, Qwen-VL):
视觉+语言统一架构 → 跨模态理解
```

## 八、技术趋势总结

### 1. 效率是核心
- **MoE架构**成为主流: 大参数量 + 低激活成本
- **注意力优化**持续演进: MHA → GQA → MQA → MLA
- **KV cache压缩**是关键瓶颈

### 2. 长文本能力
- 从4K → 32K → 128K → 200K
- 位置编码改进: RoPE + 外推技术
- 渐进式训练策略

### 3. 中文生态崛起
- Qwen、ChatGLM、Yi等国产模型
- 针对中文优化的词表和数据
- 在中文任务上超越国外模型

### 4. 多模态融合
- 视觉-语言模型成为标配
- 统一架构处理多种模态
- 工具调用和代码能力增强

### 5. 开源vs闭源
- 开源模型快速追赶闭源
- 商业友好协议(Apache 2.0)
- 社区生态日益完善

## 总结

本周研究了六个未在课程中详细讲解的开源大模型，主要发现：

1. **MoE架构**是提升效率的重要方向，Mixtral和DeepSeek-V2代表了这一趋势
2. **注意力机制优化**持续演进，从多头到分组查询到多查询到潜在注意力
3. **中文大模型**快速发展，Qwen、ChatGLM、Yi在中文任务上表现优异
4. **长文本处理**能力不断提升，200K上下文成为新标准
5. **多模态融合**是必然趋势，视觉-语言统一架构日益成熟

这些创新技术为大模型的实际应用提供了更多可能性，也为未来的研究指明了方向。
