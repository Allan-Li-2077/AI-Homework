# 事后总结（Postmortem）规则

## 一、提交时限

| 事故等级 | 提交时限 | 是否强制书面总结 | 备注 |
|---------|---------|----------------|------|
| P0 | 故障解决后 **3个工作日内** | 必须提交 | 完整事后总结文档 |
| P1 | 故障解决后 **3个工作日内** | 必须提交 | 完整事后总结文档 |
| P2 | **5个工作日内** | 必须提交 | 可简化模板 |
| P3 | 不强制要求 | 不强制 | 无需书面总结 |

## 二、数据安全事件的特殊总结要求（交叉点A延伸）

- 数据安全类事件（用户数据泄露、越权访问、数据被篡改）的事后总结，除常规内容外，**必须包含合规/法务评估结论**。
- 数据安全类事件的事后总结，**审批人必须包含法务代表**。
- 其他等级事件无此要求。
