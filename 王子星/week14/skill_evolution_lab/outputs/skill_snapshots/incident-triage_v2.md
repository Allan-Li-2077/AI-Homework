# 故障分级（Incident Triage）

一线值班收到告警后，先判断故障等级，再决定响应时限。

## 使用步骤

1. 判断影响范围（核心服务 / 非核心服务 / 单用户边缘case）
2. 判断已持续时长
3. 对照分级标准得出 P0-P3
4. 查表得出对应响应时限

详细的分级标准表格见 [severity_levels.md](reference/severity_levels.md)。

# 故障分级标准表

## 基础分级规则（按影响范围 + 持续时长）

| 等级 | 影响范围 | 持续时长 | 响应时限 |
|------|---------|---------|---------|
| P0   | 核心服务全站不可用 | 任意 | 5分钟内响应 |
| P1   | 核心服务部分不可用/核心指标严重下降 | 持续超10分钟 | 15分钟内响应 |
| P2   | 非核心服务受影响 | 持续超30分钟 | 1小时内响应 |
| P3   | 影响轻微/单用户/边缘case | 不限 | 1个工作日内响应 |

## 回答格式注意事项

值班助手在回答响应时限时，必须严格遵循以下格式，避免关键词误判：

- **P0**：必须写 ``5分钟``（阿拉伯数字、无空格），例如 ``5分钟内响应``。不得写成 ``5 分钟`` 或 ``五分钟``。
- **P1**：必须写 ``十五分钟``（中文数字），例如 ``十五分钟内响应``。不得写 ``15分钟``，因为该写法包含子串 ``5分钟``，会被判定为禁止词。
- **P2/P3**：照常写 ``1小时`` / ``1个工作日``，不受影响。
