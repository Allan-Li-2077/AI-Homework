# 文件整理规则与安全守则

> 本文件由 file-organizer Skill 引用，演示渐进式 Level 2 加载：
> LLM 先加载 SKILL.md（Level 1），看到引用后再 read_file 加载此文件（Level 2）。

## 一、文件分类规则

### 按扩展名分类

| 类别 | 扩展名 | 目标子目录 |
|------|--------|-----------|
| 文档 | `.pdf` `.doc` `.docx` `.txt` `.md` `.xlsx` `.pptx` | `documents/` |
| 图片 | `.jpg` `.jpeg` `.png` `.gif` `.bmp` `.svg` `.webp` | `images/` |
| 视频 | `.mp4` `.avi` `.mkv` `.mov` `.wmv` | `videos/` |
| 音频 | `.mp3` `.wav` `.flac` `.aac` `.ogg` | `audio/` |
| 压缩包 | `.zip` `.rar` `.7z` `.tar` `.gz` | `archives/` |
| 代码 | `.py` `.js` `.ts` `.java` `.cpp` `.html` `.css` `.json` `.yaml` | `code/` |
| 可执行 | `.exe` `.msi` `.sh` `.bat` `.ps1` | `programs/` |

### 未匹配文件
扩展名不在上表中的文件，放入 `others/` 目录。

## 二、命名规范

1. **禁止**文件名含空格——统一用下划线 `_` 替代
2. **禁止**中文文件名——转为拼音或英文描述
3. 日期格式统一为 `YYYY-MM-DD`
4. 同类文件按版本号排序：`report_v1.md` → `report_v2.md`

## 三、操作安全守则

### 必须遵守
1. **只移动、不删除**：所有操作使用 `mv`/`move` 命令，不使用 `rm`/`del`
2. **先预览、再执行**：执行前打印将执行的操作列表，用户确认后再执行
3. **冲突处理**：目标文件已存在时，自动添加 `_dup` 后缀，不覆盖

### 禁止操作
1. ❌ 不操作系统目录（`C:\Windows`、`/etc`、`/usr` 等）
2. ❌ 不操作隐藏文件（`.` 开头）
3. ❌ 不跨越盘符移动文件

## 四、整理报告模板

操作完成后输出如下格式的报告：

```
=== 文件整理报告 ===
整理目录：<path>
整理时间：<timestamp>

分类统计：
  文档：N 个文件
  图片：N 个文件
  ...

操作清单：
  ✓ <源路径> → <目标路径>
  ...

未处理文件：
  （如有）
```
