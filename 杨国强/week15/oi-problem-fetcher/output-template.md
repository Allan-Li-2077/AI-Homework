# 题目输出 Markdown 模板

所有拉取脚本统一输出此模板。

## 单文件模板（一个题）

```markdown
# [<题号>] <标题>

**平台**：<平台名>  
**题号**：<problemId>  
**链接**：<原题 URL>  
**拉取时间**：<ISO 8601 时间戳>

---

## 题目描述

<原题描述，已转 Markdown，公式用 \(...\) 或 \[...\]>

---

## 输入格式

<如原题有单独描述；否则合并到题目描述里>

## 输出格式

<同上>

---

## 样例

### 样例 1

**输入**：

```
<sample 1 input>
```

**输出**：

```
<sample 1 output>
```

### 样例 2

...

---

## 数据范围 / Hint

<如有>

---

## 标签

`<tag1>`, `<tag2>`, `<tag3>`

---

> ⚠️ 提示：原题可能含图片 / 公式渲染，请对照 [原题链接](<url>) 核对。
```

## 多文件批量（整场比赛）

比赛目录下生成 `README.md`：

```markdown
# <比赛名>

- **平台**：Codeforces / AtCoder / etc.
- **链接**：<比赛链接>
- **拉取时间**：<时间戳>
- **题目数**：<N>

## 题目列表

| # | 题号 | 标题 | 难度 | 文件 |
|---|------|------|------|------|
| A | 1800A | <title> | 800 | [1800A.md](./1800A.md) |
| B | 1800B | <title> | 1200 | [1800B.md](./1800B.md) |
| ... |
```

## 实现要求

`scripts/common.py` 提供 `write_problem_file()`，所有平台脚本都通过它输出，保证格式统一。

注意：

1. **不要**在最终输出里包含原始 HTML 标签 —— `clean_html()` 已处理
2. **样例输入输出**用 fenced code block，且不指定语言（让渲染器按纯文本处理）
3. **公式**保留为 `\(...\)`（行内）和 `\[...\]`（块），方便后续用 Pandoc 转 PDF
4. **图片**保留为 `<img src="...">`，并在文件末尾加 `⚠️ 提示：原题含图片，需手动核对`
5. **文件编码**：UTF-8 + BOM（兼容 Windows 记事本）
