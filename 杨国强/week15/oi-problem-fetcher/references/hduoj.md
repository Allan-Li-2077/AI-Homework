# HDUOJ 拉取详细说明

## 关键点：GBK 编码

HDUOJ 页面是 **GBK 编码**，脚本会强制 `response.encoding = "gbk"`，否则会乱码。

## URL

```
http://acm.hdu.edu.cn/showproblem.php?pid=<number>
```

> 注意是 `http://`，不是 `https://`

## 已知坑

- **历史题目**：很多老题没有样例展示，题面就是纯文字
- **图片题**：少量题用 `<img>` 嵌入图，HTML 抓取会保留 `<img>` 标签，但部分外链可能失效
- **网络稳定性**：HDU 服务器对高频访问敏感，建议 `--delay 1.5` 以上
- **页面结构**：HDU 改版过几次，选择器相对稳定但偶尔需要调整

## 与洛谷的"等价题"

很多 HDU 老题在洛谷上有镜像（如 `HDU 1000` ≈ `P1000`）。如果只是想要题面+样例，**优先用洛谷脚本**（更快、更稳、解析更准）。
