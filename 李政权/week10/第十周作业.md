# 第十周作业

## 一、作业说明

本作业基于手头年报摘录文件，实现一个**本地 RAG 问答系统**。核心要求是：**用代码完成问答即可，不强制网页**；方法自选。

本项目选择的技术路线：

| 模块 | 选型 |
|------|------|
| 大模型 | DeepSeek（对话生成 / 意图辅助） |
| 向量模型 | 阿里云百炼 `text-embedding-v3` |
| 向量库 | 本地 Chroma |
| 知识来源 | 贵州茅台、五粮液、泸州老窖、习酒 2022–2025 年报摘录文本 |
| 交互方式 | Python 代码调用（另附可选 Web/API，非作业必需） |

---

## 二、系统框架

### 2.1 总体架构

```text
用户问题（代码 / API）
        │
        ▼
┌───────────────────┐
│  意图识别 Intent   │  ← DeepSeek + 规则兜底
└─────────┬─────────┘
          │
   ┌──────┼──────────────────┐
   ▼      ▼                  ▼
年报问答  其他公司年报      非年报闲聊
   │      │                  │
   ▼      ▼                  ▼
 Embedding  「暂无相关知识」   DeepSeek 直答
   │
   ▼
 Chroma 检索（本地向量库）
   │
   ▼
 命中不足？──是──▶「暂无相关知识」
   │否
   ▼
 DeepSeek（带参考资料生成回答）
```

### 2.2 目录结构（核心）

```text
week10/
├── data/
│   ├── raw_texts/          # 年报摘录（问答知识库原文）
│   └── chroma/             # Chroma 持久化向量数据
├── backend/
│   ├── app/
│   │   ├── config.py       # 配置（环境变量读取 Key）
│   │   └── services/
│   │       ├── embedding.py    # 阿里云向量化
│   │       ├── chroma_store.py # Chroma 读写
│   │       ├── intent.py       # 意图分类
│   │       ├── llm.py          # DeepSeek 调用
│   │       └── rag.py          # RAG 问答主流程
│   └── scripts/
│       └── ingest.py       # 文本切分 → 向量化 → 入库
├── .env.example
└── 第十周作业.md
```

### 2.3 核心模块说明

1. **知识入库 `scripts/ingest.py`**  
   读取 `data/raw_texts/*.txt` → 文本切分 → 调用阿里云 Embedding → 写入本地 Chroma。

2. **意图识别 `services/intent.py`**  
   判断问题属于：白名单年报问答 / 其他公司年报 / 普通闲聊。

3. **检索增强 `services/rag.py`**  
   问题向量化 → Chroma 相似度检索 → 组装参考资料 → DeepSeek 生成答案。

4. **大模型 `services/llm.py`**  
   通过 OpenAI 兼容接口调用 DeepSeek。

5. **向量服务 `services/embedding.py`**  
   通过阿里云兼容接口调用 `text-embedding-v3`（维度 1024）。

## 三、实现功能

### 3.1 功能清单

1. **本地 RAG 问答**：基于四家公司年报摘录回答财务/经营相关问题。  
2. **DeepSeek 对话**：非年报问题直接调用大模型。  
3. **知识边界控制**：问到非白名单公司年报时，返回「暂无相关知识」。  
4. **检索拒答**：白名单问题但检索不到足够相关片段时，同样返回「暂无相关知识」，减少幻觉。  
5. **引用信息**：RAG 模式下可返回公司、年份、相似度与原文片段（便于核验）。  
6. **知识库构建脚本**：支持 `--reset` 重建向量索引。

### 3.2 路由规则

| 用户意图 | 处理方式 |
|----------|----------|
| 贵州茅台 / 五粮液 / 泸州老窖 / 习酒 的年报相关问题 | Embedding → Chroma → DeepSeek（RAG） |
| 其他公司年报 / 知识库无关财报问题 | 直接返回「暂无相关知识」 |
| 闲聊、常识等非年报问题 | 直接调用 DeepSeek |

### 3.3 知识库范围

- 公司：贵州茅台、五粮液、泸州老窖、习酒  
- 年份：2022、2023、2024、2025  
- 文件：`data/raw_texts/{公司}_{年份}.txt`  
- 向量条数：16（每公司每年 1 个主要文本块）

## 四、环境准备与启动

### 4.1 环境变量（API Key）

密钥通过 **Windows 系统环境变量** 配置（不要把真实 Key 写进仓库）：

```powershell
# 永久配置（新开终端后生效）
setx DEEPSEEK_API_KEY "你的DeepSeek密钥"
setx DASHSCOPE_API_KEY "你的百炼密钥"
```

或当前终端临时：

```powershell
$env:DEEPSEEK_API_KEY="你的DeepSeek密钥"
$env:DASHSCOPE_API_KEY="你的百炼密钥"
```

### 4.2 安装依赖

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### 4.3 构建向量库

> 注意：入库与查询必须使用同一套 Embedding（阿里云）。更换 Key 或首次配置后务必重建索引。

```powershell
# 在 backend 目录、已激活 venv
python -m scripts.ingest --reset
```

成功后可见集合文档数约为 16。

### 4.4 用代码完成问答（符合作业“不需要网页”）

在 `backend` 目录执行：

```powershell
python -c "from app.services.intent import classify_intent; from app.services.rag import handle_question; q='贵州茅台2023年营业收入是多少？'; intent=classify_intent(q); r=handle_question(q, intent); print(r.mode); print(r.answer)"
```

也可在 Python 中调用：

```python
from app.services.intent import classify_intent
from app.services.rag import handle_question

question = "贵州茅台2023年营业收入是多少？"
intent = classify_intent(question)
result = handle_question(question, intent)

print("模式:", result.mode)      # rag / llm / no_knowledge
print("回答:", result.answer)
print("引用数:", len(result.citations))
```

### 4.5（可选）启动 API 服务

作业不要求网页；若需联调，可启动：

```powershell
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- 健康检查：`GET /api/health`  
- 问答接口：`POST /api/chat`，Body：`{"message":"贵州茅台2023年营业收入是多少？"}`

## 五、关键代码流程说明

### 5.1 入库流程

1. 扫描 `data/raw_texts/*.txt`  
2. 按文件名解析公司、年份（如 `贵州茅台_2023.txt`）  
3. 文本切分（约 450 字/块，带重叠）  
4. 调用阿里云 Embedding 得到向量  
5. `upsert` 到 Chroma 集合 `liquor_annual_reports`

### 5.2 问答流程

1. `classify_intent(question)` 得到意图与公司/年份  
2. 若 `other_report` → 返回「暂无相关知识」  
3. 若 `chitchat` → DeepSeek 直答  
4. 若 `annual_report`：  
   - `embed_query` → Chroma `query`  
   - 按公司/年份过滤，相似度低于阈值则拒答  
   - 将命中文档作为参考资料交给 DeepSeek 生成最终答案

### 5.3 配置要点

- `DEEPSEEK_API_KEY` / `DASHSCOPE_API_KEY`：运行必需  
- `RAG_SCORE_THRESHOLD`：检索相似度阈值（默认约 0.35）  
- `CHROMA_PATH`：本地向量库路径

## 七、设计小结

1. **符合作业要求**：基于本地文件构建问答能力，核心交付是 Python RAG 代码链路，不依赖网页。  
2. **方法选择**：DeepSeek + 阿里云 Embedding + Chroma，实现可控的检索增强生成。  
3. **安全边界**：白名单外年报问题与低相似度检索统一拒答，避免模型编造财报数字。  
4. **可扩展性**：替换 `raw_texts` 为真实年报解析文本后，重新 `ingest` 即可升级知识库。
