# 第十周作业说明：易经算命 Skill 编写与优化对比

## 一、作业目标

编写一个 Agent Skill，再从**执行效率**或 **Token 消耗**等角度做优化，对比优化前后效果。

本作业交付两个版本：

| 版本 | Skill 名称 | 定位 |
|------|------------|------|
| 第一版 | `yijing-sizhu-gua1` | 初版：整页 HTML 由 LLM 生成 |
| 优化版 | `yijing-sizhu-gua` | 优化后：脚本拼装 HTML，LLM 只写解读正文 |

输入统一为：**姓名、性别、出生年月日、时辰**；输出为动态生成的八卦背景运势 HTML，并记录用时与 Token。

---

## 二、版本说明

### 2.1 第一版：`yijing-sizhu-gua1`

目录：

```text
skills/yijing-sizhu-gua1/
├── SKILL.md
└── scripts/
    └── generate_fortune_llm_html.py
```

要点：

- 四柱数字起卦（Python）
- **完整 HTML 页面由 LLM 生成**（含样式、八卦背景、解读正文）
- 输出：`outputs/fortune1/{姓名}_{时间戳}.html`
- Web：`/fortune1/{文件名}`
- 指标：`outputs/fortune1/metrics_latest.json`、`metrics_log.jsonl`

触发示例：

```text
@yijing-sizhu-gua1 算命：李明，男，1990-08-15，辰时
```

### 2.2 优化版：`yijing-sizhu-gua`

目录：

```text
skills/yijing-sizhu-gua/
├── SKILL.md
└── scripts/
    └── generate_fortune.py
```

要点：

- 起卦规则与第一版相同（可复用）
- **HTML 由 Python 动态拼装**（内联八卦 SVG，无 CDN）
- LLM **只生成解读正文**，再嵌入页面
- 输出：`outputs/fortune/{姓名}_{时间戳}.html`
- Web：`/fortune/{文件名}`
- 指标：`outputs/fortune/metrics_latest.json`、`metrics_log.jsonl`

触发示例：

```text
算命：李明，男，1990-08-15，辰时
```

## 三、两版区别（一句话）

| 项目 | 第一版 `yijing-sizhu-gua1` | 优化版 `yijing-sizhu-gua` |
|------|---------------------------|---------------------------|
| HTML | 整页由 LLM 生成 | Python 脚本拼装 |
| 解读 | 含在 LLM 输出的 HTML 中 | LLM 只写正文 |
| Token | 高 | 明显更低 |
| 耗时 | 长 | 更短 |
| 稳定性 | 易触 `max_tokens` 截断，可能 fallback | 页面结构稳定 |

**优化思路：** 把「页面结构 / 样式 / 八卦背景」从模型挪到脚本，模型只负责文案，从而降低 Token 与耗时，并减少 HTML 被截断的风险。

## 四、实测对比

同类任务下的典型区间（DeepSeek，见各目录 `metrics_*.json`）：

| 指标 | 第一版 `yijing-sizhu-gua1` | 优化版 `yijing-sizhu-gua` |
|------|---------------------------|---------------------------|
| 模式 | `llm_html` | `llm`（脚本出页） |
| 用时 | 约 38～46 s | 约 14～31 s |
| Total Tokens | 约 4900～6400 | 约 1100～2700 |
| 稳定性 | 曾出现 `fallback=true` | 落盘可靠 |

## 五、运行方式

```bash
# 安装依赖
pip install -r requirements.txt

# 配置 API Key（PowerShell 示例）
$env:DEEPSEEK_API_KEY = "sk-xxx"

# 第一版：LLM 生成整页 HTML
python skills/yijing-sizhu-gua1/scripts/generate_fortune_llm_html.py "@yijing-sizhu-gua1 算命：李明，男，1990-08-15，辰时"

# 优化版：脚本 HTML + LLM 解读
python skills/yijing-sizhu-gua/scripts/generate_fortune.py "算命：李明，男，1990-08-15，辰时"

# Web 演示
uvicorn src.serve:app --host 127.0.0.1 --port 8000
# 浏览器打开 http://127.0.0.1:8000
```

---

## 六、结论

1. **第一版**功能完整，但让模型生成整页 HTML，Token 高、耗时长、易截断。  
2. **优化版**由脚本生成 HTML、模型只写解读，Token 与耗时明显下降，页面更可控。  
3. Skill 优化时，宜把确定性步骤（排版、起卦、落盘）留给代码，把创造性步骤留给模型。
