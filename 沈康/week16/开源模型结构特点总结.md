## 1. DeepSeek 系列

### 1.1 DeepSeek-V3

#### 模型定位
DeepSeek-V3 是 DeepSeek 在 V2 基础上推出的 MLA + MoE 旗舰基座模型，也是后续 DeepSeek-R1（纯 RL 推理模型）的架构底座。

#### 关键结构参数

| 维度 | 数值 | 说明 |
|------|------|------|
| 总/激活参数 | **671B / 37B** | 激活占比约 1:18 |
| 层数/隐藏维度 | 61 层 / 7168 | 前 3 层为 Dense FFN，后续 58 层 MoE |
| 注意力机制 | **MLA（Multi-head Latent Attention）** | Q 和 KV 分别做低秩投影 |
| 注意力头 | 128 头 | 头维度由 MLA 低秩重建 |
| Q / KV 低秩秩（参考） | 典型配置 `q_lora_rank ≈ 1536`、`kv_lora_rank ≈ 512` | 源自同系列 **V3.2** 官方建模代码；V3 精确值以对应 config.json 为准 |
| RoPE 维度拆分（参考） | 典型 `qk_nope ≈ 128 + qk_rope ≈ 64` | 仅约 64 维施加旋转位置编码；同上参考 V3.2 实现 |

#### MoE 结构
- **专家配置**：1 个共享专家 + **256 个路由专家**（细粒度，中间维度 2048）
- **Top-k 路由**：每 token 从 256 专家中选 **top-8 路由专家 + 1 共享专家** = 共激活 9 个专家
- **路由打分**：**Sigmoid** 亲和性分数（非 Softmax）
- **负载均衡**：**Auxiliary-Loss-Free（无辅助损失）** + 动态偏置路由
- **共享专家作用**：承载跨上下文通用知识（句法、通用推理），让路由专家集中学领域知识

#### 长上下文与位置编码
- 原生上下文：128K / 163,840 tokens
- 位置编码：YaRN RoPE 扩展
- KV cache 压缩：相比标准 MHA，每 token 仅缓存 576 维（压缩约 10 倍），KV cache 减少 **93.3%**

#### 其他工程特性
- 量化：FP8 混合精度训练与推理路径
- 多 token 预测：MTP（Multi-Token Prediction）模块
- 并行：支持 Vocab Parallel Embedding、Column/Row Parallel Linear 的张量并行

#### 核心创新
1. **MLA 压缩 KV**：把 KV 投影到低秩 latent 空间，推理时重建，大幅缓解长上下文显存瓶颈
2. **无辅助损失路由**：用可学习偏置而非辅助损失梯度实现专家负载均衡
3. **前 3 层 Dense**：保证浅层语义表示稳定，不早期路由

### 1.2 DeepSeek-R1

#### 模型定位
DeepSeek-R1 是基于 DeepSeek-V3 架构、通过大规模强化学习训练的推理模型。**其核心创新不在网络结构，而在训练策略**：直接从 base 模型出发用纯 RL（GRPO）训练，无需 SFT 冷启动即可涌现强推理能力，是"结构不变、训练换道"的代表作。

#### 关键结构参数

| 维度 | 数值 | 说明 |
|------|------|------|
| 架构底座 | **与 DeepSeek-V3 相同** | 671B / 37B，MLA + MoE，结构未改动 |
| 层数/隐藏维度 | 61 层 / 7168 | 与 V3 相同 |
| 注意力机制 | MLA | 与 V3 相同 |
| MoE 路由专家 | 256 + 1 共享 | 与 V3 相同 |
| Top-k 激活 | 8 路由 + 1 共享 | 与 V3 相同 |
| 原生上下文 | 128K | 与 V3 相同 |
| 路由打分 | Sigmoid，无辅助损失 | 与 V3 相同 |

> R1 的 MoE 架构与 V3 完全一致，推理能力完全来自 RL 训练策略，而非结构改动。

#### 训练策略核心创新
1. **纯 RL（GRPO）从 base 直接训练**：不依赖 SFT 冷启动，直接对 V3 base 模型施加 Group Relative Policy Optimization，让模型自行探索推理链路
2. **推理能力涌现**：随 RL 训练推进，模型自发产生反思、验证、长链路推理行为，无需人工标注 CoT
3. **蒸馏版本**：将 R1 的推理能力蒸馏到 Qwen / Llama 等小模型系列（1.5B ~ 70B 多个尺寸），证明强推理可迁移到稠密小模型
4. **训练成本可控**：纯 RL 路线大幅降低了高质量推理数据的标注成本

#### 与 V3 的关系
- V3 提供"结构底座"：MLA + 256 专家 MoE + 128K 上下文
- R1 提供"训练范式"：纯 RL 直接训出推理能力
- 二者叠加 = 强结构底座 + 强训练策略，是开源推理模型的标志性组合

## 2. Qwen 系列

### 2.1 Qwen3-Next-80B-A3B

#### 模型定位
Qwen3-Next-80B-A3B 是 Qwen3-Next 架构的开源旗舰，代表"线性注意力工业化 + MoE 极致稀疏"方向。80B 总参数仅激活 3.9B（占比约 4.9%），是本汇总中激活率最低的模型之一，许可证为 Apache 2.0。

#### 关键结构参数

| 维度 | 数值 |
|------|------|
| 总/激活参数 | **80B / 3.9B**（激活占比约 4.9%，极致稀疏） |
| 层数 | 48 层 |
| 注意力机制 | Gated DeltaNet（线性）+ Gated Attention（full softmax）混合 |
| 混合比例 | **3:1**（每 4 层 = 3 层 Gated DeltaNet + 1 层 Gated Attention） |
| MoE 专家数 | **512 路由专家 + 1 共享** |
| Top-k 激活 | **10 路由 + 共享** |
| 原生上下文 | 262,144 tokens（可通过 YaRN 扩展到 ~1M） |
| 额外能力 | MTP 多 token 预测 |
| 许可证 | Apache 2.0 |

#### 混合注意力结构
48 层并非全量标准 self-attention，而是按周期排布：

```
12 × (3 × Gated DeltaNet / linear_attention → FFN
        1 × Gated Attention / full_attention → FFN)
```

即：
- **36 层 Gated DeltaNet（线性注意力）**：75% 的层承担低成本序列状态更新
- **12 层 Gated Attention（全注意力）**：每 4 层插入 1 层，用于高精度全局检索

**Gated DeltaNet 内部机制**：
- 核心是 delta rule 递推：维护固定大小状态矩阵，`O(1)` 显存、`O(n)` 计算
- 带深度卷积做局部邻域混合
- 支持 chunk 模式 fused kernel 加速训练
- **与 MLA 的本质区别**：Qwen3-Next 用 delta rule 线性注意力，而非 MLA 低秩重建

#### 训练稳定性优化
- **zero-centered weight-decayed layernorm**：兼顾归一化与权重衰减的稳定性设计，支撑 48 层 + 512 专家的大规模 MoE 稳定训练

#### 长上下文
- 原生 262,144 tokens
- 可通过 YaRN 扩展到约 1M tokens
- 周期性 full-attention 层弥补了线性注意力缺失的精确检索能力，只有约 1/4 层产生传统 KV 长度增长

## 3. Kimi 系列

### 3.1 Kimi K2

#### 模型定位
Kimi K2 是月之暗面开源的万亿参数级 MoE 模型，基于 DeepSeek-V3 风格的纯 MLA + MoE 架构，主打 **Agent 能力**：大规模 agentic 数据合成 + 通用 RL 框架，是本汇总中参数量最大的模型。许可证为 MIT（修改版）。

#### 关键结构参数

| 维度 | 数值 | 对比 V3（参考） |
|------|------|------|
| 总/激活参数 | **~1T / 32B** | ~671B / 37B |
| 架构 | 纯 MLA + MoE | 纯 MLA + MoE |
| 层数 | 61 层（1 Dense + 60 MoE） | 61 层（前 3 Dense + 58 MoE） |
| attention hidden | 7168 | 7168 |
| MoE hidden | 2048 | 2048 |
| 注意力头数 | **64 头**（V3 为 128 头） | 128 头 |
| MoE 路由专家 | **384 个** + 1 共享 | 256 个 + 1 共享 |
| Top-k 激活 | **8 路由 + 1 共享** | 8 + 1 |
| 路由打分 | Sigmoid + `routed_scaling` | Sigmoid |
| 激活函数 | SwiGLU（silu） | SwiGLU（silu） |
| 词汇表 | 160K | — |
| 原生上下文 | **128K**（无 YaRN 外推） | 128K（YaRN 扩展） |

> **注**：K2 与 DeepSeek-V3 的 MLA 结构高度相似，公开资料指出二者"结构几乎一致"，主要改动见下。K2 官方 config 中 MLA 低秩参数（q/kv_lora_rank）的精确值应以其公开配置为准。

#### K2 对 V3 架构的关键改动
1. **注意力头从 128 减到 64**：降低长上下文 Agent 场景的推理延迟
2. **Dense 前置层缩减为 1 层**（V3 为 3 层）
3. **原生 128K 上下文，不使用 YaRN 外推**（区别于原 K2.6 设定）
4. **路由专家增至 384**（V3 为 256），叠加 `routed_scaling` 控制稀疏路由强度

#### K2 独特创新
1. **MuonClip 优化器（Muon + QK-Clip）**：在 Muon 优化器上引入按头 QK 权重裁剪，万亿参数训练全程零 loss spike，是本汇总中唯一在优化器层解决万亿训练稳定性的模型
2. **主打 Agent 能力**：大规模 agentic 数据合成 + 通用 RL 框架，面向工具调用、长程规划等 Agent 任务

#### 长上下文与位置编码
- 原生上下文：**128K tokens**（非 256K，无 YaRN 外推）
- KV cache 压缩：MLA 低秩 latent 投影，与 V3 同路线

## 4. MiniMax 系列

### 4.1 MiniMax-01

#### 模型定位
MiniMax 官方开源的纯文本基座模型，核心创新是 **Lightning Attention（闪电注意力）** 的大规模工业落地，把线性注意力从"小模型实验"推到了数百亿激活参数 + 百万上下文规模。（MiniMax-VL-01 是独立的视觉语言版本，不在本汇总范围内。）

#### 关键结构参数

| 维度 | 数值 |
|------|------|
| 总/激活参数 | **456B / 45.9B** |
| 层数 / 隐藏维度 | 80 层 / 6144 |
| 注意力模块 | 64 头 / head_dim 128 |
| MoE 专家数 / Top-k | 32 专家 / Top-2 路由 |
| 专家 hidden | 9216 |
| RoPE base | 10,000,000 |
| 词表大小 | 200,064 |
| 训练上下文 | 1,000,000 tokens |
| 推理外推方案 | 可外推到 4M tokens |

#### Lightning Attention 的核心结构
MiniMax-01 没有使用 KDA/Gated DeltaNet，而是采用 **7 个线性注意力块 + 1 个 softmax 注意力块**的周期结构（比例 7:1），线性部分源自 TransNormer/Lightning Attention：

```
每 8 层为一个 Block：
  层 1~7：Lightning 线性注意力
  层 8：标准 Softmax 注意力（锚点层）
```

**Lightning Attention 不是简单滑窗**：
- 块内 token 使用**局部因果注意力**（保证短距离关系 + Tensor Core 友好）
- 块间不再计算完整 `QK^T`，而是递推维护固定大小的 **`K^T V` 状态**
- 把因果累加拆成"块内左乘 + 块间右乘"，从而把长序列计算降为**近似线性复杂度**

**为什么仍需要 softmax 锚点层（每 8 层 1 层）**：
- 线性状态是有损压缩，纯线性注意力会丢失精确检索能力和 in-context learning 表现
- 7:1 的比例是速度、检索精度、硬件利用率之间的经验折中

#### MoE 配套与稳定化
- 每层 FFN：32 专家 / Top-2 激活
- **Global Router**：在 Expert Parallel 组之间先同步各专家待处理 token 数，再做 dispatch，降低不同并行组之间的负载不均和 token 丢弃
- **DeepNorm**：支撑较深的 Post-Norm 训练稳定性（80 层深度）

### 4.2 MiniMax-M1

#### 模型定位
MiniMax-M1 是基于 MiniMax-01 架构、通过 RL 增强推理能力的推理模型。**结构与 MiniMax-01 完全相同，核心创新在 RL 算法（CISPO）与推理效率**，是"结构不变、训练/推理换道"的代表，与 DeepSeek-R1（基于 V3）属同一范式。

#### 关键结构参数

| 维度 | 数值 | 说明 |
|------|------|------|
| 架构底座 | **与 MiniMax-01 相同** | 456B / 45.9B，结构未改动 |
| 注意力机制 | Lightning Attention + Softmax 7:1 混合 | 与 01 相同 |
| MoE 专家数 / Top-k | 32 专家 / Top-2 | 与 01 相同 |
| 训练/推理上下文 | 1M tokens | 与 01 相同 |

> M1 的网络结构与 MiniMax-01 完全一致，推理能力来自 CISPO RL 算法与 thinking budget 设计。

#### 训练与推理策略核心创新
1. **CISPO RL 算法**（Clipped IS-weight Policy Optimization）：裁剪重要性采样权重的策略优化算法，稳定 RL 训练，避免传统 PPO 在长链路推理中的方差爆炸
2. **两个 thinking budget 版本**：
   - **M1-40k**：thinking budget 40k tokens
   - **M1-80k**：thinking budget 80k tokens
   - 通过控制推理预算灵活权衡延迟与质量
3. **极低 RL 训练成本**：仅用 **512 张 H800 GPU，3 周完成，成本约 $534,700**，远低于同规模推理模型的 RL 训练开销
4. **推理效率优势**：100K token 生成长度时，FLOPs 仅为 DeepSeek-R1 的 **25%**——得益于 Lightning Attention 线性复杂度在长生成场景的天然优势

#### 与 MiniMax-01 的关系
- 01 提供"结构底座"：Lightning Attention 7:1 + 32 专家 MoE + 1M 上下文
- M1 提供"训练范式"：CISPO RL + thinking budget
- 证明线性注意力基座也能高效支撑强推理模型，且 RL 训练成本可控

## 5. 腾讯混元系列

### 5.1 Hunyuan-A13B

#### 模型定位
腾讯混元开源的高性价比 MoE 模型，核心是把"旗舰级细粒度 MoE 配方"下放到 **80B 总参数 / 13B 激活参数**的可部署规模，是学习"中等规模模型如何设计 MoE"的重要工程样例。

#### 关键结构参数

| 维度 | 数值 |
|------|------|
| 总/激活参数 | **80B / 13B** |
| 层数 / 隐藏维度 | 32 层 / 4096 |
| 注意力机制 | **标准 GQA + QK-Norm**（不走 MLA/线性路线） |
| 注意力头/KV 头 | 32 / 8（GQA 4:1） |
| 上下文长度 | **原生 256K**（支持 NTK 外推） |
| 长上下文预训练 | 三阶段：4K 基础 → 8K 退火 → NTK 外推到 32K→256K |
| 预训练数据量 | 20T tokens |
| 激活函数 | SwiGLU |

#### MoE 结构：细粒度高性价比配方
Hunyuan-A13B 的 MoE 配置是本次汇总中"专家数量不多但激活率低"的代表：

| MoE 参数 | 数值 |
|------|------|
| 共享专家 | **1 个**（所有 token 始终激活） |
| 非共享路由专家 | **64 个** |
| Top-k 激活路由专家 | **8 个** |
| 每 token 总激活专家 | 8 路由 + 1 共享 = 9 个 |
| 专家隐层维度 | **3072**（单个专家较窄） |

**结构含义**：
- 共享专家 → 提供通用变换能力
- 64 个非共享专家 → 承载更细分领域的专门化知识
- 与"少量大专家"相比，更多更小专家可实现更细粒度组合
- 与 256/512 专家的旗舰相比，A13B 展示了这一思路如何下放到 80B 规模，并保持较低激活量（13B）

#### 独特特性
1. **快慢思考双模式**：一个模型内同时支持 `fast thinking`（`/no_think`）和 `slow thinking`（`/think`）双推理模式，属于推理/训练策略，不引入新网络层
2. **发布版本齐全**：Pretrain、Instruct、FP8、GPTQ-Int4 四个版本均开源
3. **CLA（Cross-Layer Attention）**：跨层注意力进一步压缩 KV cache
4. **细粒度 MoE 逐层配置**：`moe_intermediate_size` 是 32 元素的逐层列表，每个专家 FFN 可调
5. **专家级差异化学习率**：不同专家 FFN 用不同学习率训练

## 6. 其他前沿模型

### 6.1 ERNIE 4.5

#### 模型定位
百度 PaddlePaddle/ERNIE 开源的多模态 MoE 家族，最大特色是**把多模态差异下沉到 MoE 路由和参数分工层面**，而不只是停留在"视觉塔 + projector"的传统外挂形态。许可证为 Apache 2.0。

#### 模型规格概览

| 型号 | 总/激活参数 | 定位 |
|------|------|------|
| 纯文本旗舰 | 300B / 47B | 纯文本 |
| 多模态旗舰 | 424B / 47B | 视觉语言 |
| 轻量 VL 型号 | 28B / 3B | 可部署多模态 |
| 稠密小模型 | 0.3B | 稠密 |
| 上下文窗口 | 128K | 通用 |

#### 300B 旗舰关键结构参数

| 维度 | 数值 |
|------|------|
| 总/激活参数 | 300B / 47B |
| 层数 | 54 层 |
| 注意力头 / KV 头 | 64 query heads / 8 KV heads（GQA 8:1） |
| 原生上下文 | 128K |

#### 异构多模态 MoE：共享与专属并存
ERNIE 4.5 的核心结构思想是"参数分成三类 + 模态隔离路由"：

| 参数类型 | 是否跨模态共享 | 数量/激活 | 作用 |
|------|------|------|------|
| **共享参数** | 是（文本 + 视觉都经过） | — | 学习跨模态共性语义 |
| **文本专属专家** | 否（仅文本 token 可路由到） | 64 文本专家 / 8 激活 | 避免视觉梯度稀释语言能力 |
| **视觉专属专家** | 否（仅视觉 token 可路由到） | 64 视觉专家 / 8 激活 | 避免语言梯度干扰视觉统计 |

路由机制：**Modality-Isolated Routing（模态隔离路由）**
- 在进行专家选择前，先按模态边界在各自专家池内进行路由
- 文本 token 只在"共享 + 文本专属"专家中选择
- 视觉 token 只在"共享 + 视觉专属"专家中选择

配套训练损失：
1. **Router Orthogonal Loss（路由正交损失）**：约束不同模态之间的路由方向不互相干扰
2. **Multimodal Token-Balanced Loss（多模态 token 均衡损失）**：同时考虑文本和视觉 token 的负载均衡

#### 工程配套
- 训练/推理全栈：PaddlePaddle + ERNIEKit，覆盖 Pretrain、SFT、DPO、QAT、多硬件部署
- 并行策略：Heterogeneous Hybrid Parallelism（异构混合并行）+ Hierarchical Load Balancing
- 量化：FP8 混合精度
- 许可：Apache 2.0

#### 结构意义
回答了多模态预训练的核心问题："视觉数据会不会稀释语言模型能力？"
ERNIE 4.5 的结构回答是：**共享一部分学共性，隔离一部分学特性，让路由器显式处理模态冲突**，而不是强迫"同一个 FFN 同时学语言统计和视觉统计"。

### 6.2 Janus-Pro

#### 模型定位
DeepSeek 开源的统一多模态理解与生成模型，核心创新是**双视觉编码路径解耦**——理解和生成不共用视觉表示，但共享同一个自回归 Transformer 主干。许可证为 MIT。

#### 模型规格
- 公开型号：Janus-Pro-1B、Janus-Pro-7B
- 序列长度：4096 tokens
- 统一骨架：单个自回归 Transformer（文本主干共享）
- 许可证：MIT

#### 双视觉编码路径结构
Janus-Pro 没有用"一个 ViT + projector 同时服务理解和生成"，而是明确拆成两条独立路径：

| 任务 | 视觉编码器 | 适配方式 | 输出形态 |
|------|------|------|------|
| **多模态理解** | **SigLIP** | Understanding Adaptor 映射到 LLM 输入空间 | **连续视觉特征序列** |
| **视觉生成** | **VQ Tokenizer** | Generation Adaptor 映射 codebook embedding | **离散图像 token 序列** |

两条路径的具体流程：
```
理解路径：图像 → SigLIP → Understanding Adaptor → 连续视觉特征 → 拼入序列
生成路径：图像 → VQ Tokenizer → Generation Adaptor → 离散图像 token → 拼入序列
                        ↓                                  ↓
                 共享自回归 Transformer 主干（统一处理）
```

然后两类视觉特征拼接成统一多模态序列，交给**同一个自回归 Transformer 主干**处理：
- 共享部分：语言建模 Transformer 主干
- 不共享部分：视觉输入表示（理解用连续 SigLIP 特征 / 生成用离散 VQ token）
- 输出头：语言预测头共享，图像生成任务额外设图像 token prediction head

#### 为什么要解耦
视觉理解和视觉生成的目标本身存在梯度冲突：
- **理解需要**：高层语义、跨图文对齐、强空间/物体识别能力
- **生成需要**：可逆或近似可逆的离散视觉 token、稳定的图像 token 自回归预测
- 强迫一个视觉编码器同时优化两个目标，会导致两者都学不好

Janus-Pro 的方案：共享 Transformer 保留统一语义空间，双视觉编码路径则把"梯度冲突"在输入层就拆开。

### 6.3 Ling-3.0-flash

#### 模型定位
基于 Kimi Delta Attention（KDA）+ 门控 MLA + 大规模稀疏 MoE 的纯文本 Causal LM，公开模型信息概括为约 **124B 总参数 / 约 5.1B 激活参数** 的混合线性 MoE 模型，配置类型为 `BailingMoeV3ForCausalLM` / `bailing_hybrid`。

> **注**：此模型公开信息有限，部分参数来自配置文件分析，精确值以官方发布为准。

#### 主干结构

```
Token
  → 前 2 个 Dense Transformer 层（基础表示）
  → 40 层混合注意力 + 稀疏 MoE：
       35 层 KDA（Kimi Delta Attention，线性注意力）
       7 层 门控 MLA（高精度全局检索，比例约 5:1）
       + 每层 FFN = 稀疏 MoE（512 专家选 8 + 1 共享）
  → LM Head
```

#### 关键结构参数

| 维度 | 数值 |
|------|------|
| 层数 | 42（前 2 Dense + 后 40 混合） |
| 隐藏维度 | 2560 |
| 注意力头数 | 32（门控 MLA 头规模） |
| KDA : 门控 MLA | 35 : 7（约 5:1） |
| 路由专家数 | **512 个** |
| 每 token 激活 | 8 路由 + 1 共享 = 9 专家 |
| 专家中间维度 | 768（单个专家窄，靠数量扩容量） |
| Dense FFN 中间维度 | 6144（前 2 Dense 层更宽） |
| 原生上下文 | 262,144（256K 级） |
| 位置编码 | RoPE，`rope_theta ≈ 6,283,185`，旋转维度 64 |
| 路由评分 | Sigmoid + `topk_method = noaux_tc`（无辅助损失） |
| 短卷积核 | `short_conv_kernel_size = 4`（线性注意力局部混合） |
| NextN/MTP | 1 个额外多 token 预测层 |

> **注**：以上参数来自配置文件分析，`rope_theta` 等字段以实际官方 config 为准。

#### 门控 MLA 细粒度拆分
- Q/K 表示分成 `qk_nope_head_dim = 128` + `qk_rope_head_dim = 64` 两部分
- `use_qk_norm = true`（QK 归一化）
- `gated_attention_proj_granularity_type = head_wise`（逐头粒度控制注意力投影）

#### KDA 层机制
- 通过递归状态 + 短卷积吸收历史信息，推理时不必让每个 query 访问完整历史
- `kda_safe_gate = true` + `kda_lower_bound = -5.0`：KDA 门控更新带稳定性下界约束
- 7 个门控 MLA 层作为"高精度全局检索锚点"，补偿线性注意力的长距离精确匹配损失

## 8. 架构演进趋势总结

从以上 10 个经验证的真实开源模型，可以梳理出当前大模型结构演进的几个清晰方向：

### 8.1 注意力机制：从二分法走向"混合配方"
没有一条路线能够一统天下，各家都在"**低成本主力层 + 少量高精度锚点层**"之间做比例折中：

| 混合范式 | 代表模型 | 主力层（低成本） | 锚点层（高精度） | 比例 |
|------|------|------|------|------|
| 线性注意力 + Full Attn | Qwen3-Next-80B-A3B | Gated DeltaNet（线性递推） | Gated Attention（softmax） | 3:1 |
| Lightning + Softmax | MiniMax-01 / M1 | Lightning（块内局部 + 块间递推） | 标准 Softmax | 7:1 |
| KDA + 门控 MLA | Ling-3.0-flash | KDA（递归状态 + 短卷积） | 门控 MLA | 5:1 |
| 纯 MLA 坚持派 | DeepSeek-V3 / R1、Kimi K2 | 全层 MLA | — | 100% |
| GQA + 归一化增强 | Hunyuan-A13B | 全层标准 GQA | — | 100% |

### 8.2 MoE 设计：细粒度 + 共享专家成为范式
- 专家数从 Mixtral 的 8 个持续增长：32（MiniMax-01/M1）→ 64（Hunyuan-A13B）→ 256（DeepSeek-V3/R1）→ 384（Kimi K2）→ 512（Qwen3-Next、Ling-3.0-flash）
- 激活率持续走低：DeepSeek-V3 约 5.5%、Kimi K2 约 3.2%、Qwen3-Next 约 4.9%、Ling-3.0-flash 约 4.1%——极致稀疏成为旗舰标配
- 共享专家几乎成为标配（ERNIE 4.5 还扩展到模态专属专家）
- 路由打分：Sigmoid 全面取代 Softmax；Kimi K2 叠 `routed_scaling`；Ling 用 `noaux_tc` 无辅助损失
- 负载均衡：从"辅助损失"（早期）→ "无辅助损失 + 偏置"（V3/R1、K2）→ "模态隔离 + 正交 loss"（ERNIE 4.5）

### 8.3 长上下文：1M 训练成为线性注意力基座标配，128K~256K 为 MLA/GQA 基线
- 原生 1M 上下文训练：MiniMax-01、MiniMax-M1（加排除的 GLM-5.2、Kimi-K3）
- 原生 262K：Qwen3-Next-80B-A3B（可扩 ~1M）
- 原生 256K：Hunyuan-A13B、Ling-3.0-flash
- 原生 128K：DeepSeek-V3/R1、Kimi K2、ERNIE 4.5
- 位置编码三条路线并存：
  1. **YaRN / NTK 外推**（DeepSeek-V3、Hunyuan-A13B 三阶段 NTK）
  2. **抬 rope_theta 原生长上下文**（MiniMax-01 `10,000,000`、Ling ≈ `6,283,185`）
  3. **递推状态隐式编码顺序**（Gated DeltaNet、KDA、Lightning Attention 线性层——这些层里 RoPE 不再是必须的）
- **Kimi K2 走原生 128K 无外推路线**，靠 MLA KV 压缩支撑，是纯 MLA 路线的务实选择

### 8.4 多模态：从"外挂视觉塔"走向两条进阶路线
1. **多模态差异下沉到 MoE 路由**：ERNIE 4.5（共享参数 + 模态专属专家 + 隔离路由），把"视觉会不会稀释语言"问题在路由层显式处理
2. **理解/生成目标解耦**：Janus-Pro（SigLIP 理解路径 + VQ 生成路径 → 共享 Transformer 主干），把梯度冲突在输入层拆开
- 注：MiniMax-VL-01 是独立的 VL 版本，不走"基座内嵌视觉塔"路线

### 8.5 推理能力：从"堆结构"转向"结构不变 + RL 换道"
本汇总最显著的趋势是**推理模型的架构与基座模型相同，创新全部在训练策略**：
- **DeepSeek-R1**：与 V3 同结构，纯 RL（GRPO）从 base 直接训练出推理能力，无需 SFT 冷启动；并蒸馏到 1.5B~70B 小模型
- **MiniMax-M1**：与 01 同结构，CISPO RL 算法 + thinking budget（40k/80k 两版本），RL 训练仅 512 H800、3 周、$534,700，100K 生成长 FLOPs 仅为 R1 的 25%
- **Hunyuan-A13B**：快慢双模式（`/think`、`/no_think`），同一结构内切换推理深度

### 8.6 推理效率：量化与 MTP 成为架构一等公民
- **量化训练原生集成**：DeepSeek-V3 FP8；Hunyuan-A13B 官方 FP8/Int4 版本；Kimi K2 原生 INT4 发布
- **MTP（多 token 预测）**：DeepSeek-V3、Qwen3-Next、Ling-3.0-flash 都显式包含 MTP/NextN 层，同时服务训练信号增强与推理投机解码
- **测试时缩放（Thinking 控制）**：MiniMax-M1 thinking budget、A13B 快慢模式——模型结构与解码策略联合设计取代单纯堆参数

```
Phase 3  线性注意力/递推状态时代 2024 H2 主流（数学层消灭 O(n²)）
         用 delta rule / kernel / K^T V 递推把 attn 写成 O(n)，彻底消除 KV 长度依赖
         配合周期性插入 softmax full attn 做精度校准
         代表：Gated DeltaNet (Qwen3-Next)、Lightning (MiniMax-01/M1)、KDA (Ling)
```

### 9.3 演进收敛判断

综合上表和 §8.3 的趋势，长上下文的"胜利条件"已经从单一技巧转向**三层联合设计**：

1. **位置编码层**：默认选用 **Phase 2 高 theta + QK-Norm** 的保守稳定基线；
2. **注意力计算层**：默认选用 **Phase 3 线性注意力为主 + 低频 full attn 校准** 的数学层 O(n) 方案；
3. **系统工程层**：在需要极端 1M+ 或更严格推理预算时，叠加 **Phase 2B 的 MLA/压缩/稀疏** 技巧作为额外加速项。

三者叠加后，2025 之后的开源旗舰 MoE，256K~1M 原生上下文将不再是卖点，而是默认标配。同时，**推理能力的获取正在从"改结构"转向"结构不变 + RL 换道"**（DeepSeek-R1、MiniMax-M1），长上下文基座与强推理能力的解耦成为新趋势。
