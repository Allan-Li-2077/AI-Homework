## 修改点
1. 新增skill_loader文件,用于渐进式加载skill
2. 在原有的agent.py文件里先获取到skill的名字和描述信息 注如到系统提示词里.
3. LLM 快速探测 → 输出是否含 SKILL_TRIGGER:<name>  未命中:直接流式输出回答（原逻辑不变）  命中:加载完整 SKILL.md 指令 → 注入 系统提示词中
4. SkillExecutor 从回答中提取代码块 → 写文件 → 执行脚本使用.
