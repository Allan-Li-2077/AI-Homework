# 古诗词知识图谱技能

# 输出要求
- 结构化分点输出，覆盖具体诗名、人名、字号、名句与术语。
- 名句逐字引用原句，人名给出字号全称，术语使用标准表述。

# 格律术语
- 平仄：汉字声调分平声与仄声。平声含阴平、阳平；仄声含上声、去声。
- 押韵：韵脚通常在偶数句末；近体诗一韵到底，不换韵。
- 对仗：律诗颔联、颈联必须对仗；工对为工整的对仗。

# 诗体体制
- 古体诗：不拘格律，对平仄、对仗没有严格要求。
- 近体诗：格律诗，对平仄、押韵、对仗有严格规定；主要包括绝句与律诗。
- 绝句：全诗四句，分为律绝（符合律诗格律）与古绝（不受格律限制）。
- 律诗：全诗八句，分首联、颔联、颈联、尾联；颔联与颈联必须对仗。

# 词的体制
- 词牌：填词用的曲调名，决定词的格式与字数。
- 词的结构：分上阕（上片）与下阕（下片）。
- 词的别称：长短句、诗余。

# 散曲
- 散曲包括小令与套数两种体制。
- 曲牌：曲的曲调名。

# 宋代词人
- 柳永：字耆卿，人称奉旨填词柳三变。北宋婉约派代表词人。
- 柳永《雨霖铃·寒蝉凄切》：寒蝉凄切，对长亭晚，骤雨初歇。执手相看泪眼，竟无语凝噎。表达离别之痛。
- 苏轼：字子瞻，号东坡居士。豪放派代表词人。
- 辛弃疾：字幼安，号稼轩。南宋豪放派代表词人。
- 辛弃疾《青玉案·元夕》：众里寻他千百度，蓦然回首，那人却在，灯火阑珊处。
- 辛弃疾《破阵子·为陈同甫赋壮词以寄之》：醉里挑灯看剑，梦回吹角连营。
- 苏轼《念奴娇·赤壁怀古》：大江东去，浪淘尽，千古风流人物。
- 苏轼《水调歌头·明月几时有》：明月几时有，把酒问青天。但愿人长久，千里共婵娟。小序提到丙辰中秋。
- 苏轼《江城子·密州出猎》：老夫聊发少年狂。属豪放派代表作。
- 苏轼《江城子·乙卯正月二十日夜记梦》：十年生死两茫茫，不思量，自难忘。
- 李清照：号易安居士。宋代婉约派代表词人。
- 李清照《声声慢》：寻寻觅觅，冷冷清清，凄凄惨惨戚戚。开篇连用七组叠字。
- 李清照《如梦令》：知否，知否？应是绿肥红瘦。

# 建安风骨与魏晋
- 建安风骨代表：三曹（曹操、曹丕、曹植）。
- 曹操《观沧海》：东临碣石，以观沧海。日月之行，若出其中。
- 曹植《七步诗》：煮豆燃豆萁，豆在釜中泣。讽刺其兄曹丕迫害。
- 陶渊明：田园诗派开创者。《饮酒·其五》：采菊东篱下，悠然见南山。

# 诗派与群体
- 初唐四杰：王勃、杨炯、卢照邻、骆宾王。
- 王勃《滕王阁序》：落霞与孤鹜齐飞，秋水共长天一色。描写秋景的千古名句。
- 山水田园诗派：代表诗人王维、孟浩然。
- 王维：字摩诘，尊称诗佛。苏轼评其「诗中有画，画中有诗」。名篇《相思》：红豆生南国，春来发几枝。
- 孟浩然：山水田园诗派代表。

# 文学理论与先秦诗歌
- 诗经六义：风、雅、颂为体裁；赋、比、兴为表现手法。

# 唐代诗人
- 白居易：字乐天，号香山居士。唐代现实主义诗人，新乐府运动倡导者。
- 白居易《长恨歌》：在天愿作比翼鸟，在地愿为连理枝。表达爱情誓言。
- 白居易《琵琶行》：同是天涯沦落人，相逢何必曾相识。表达同病相怜。
- 李白：字太白，号青莲居士，人称谪仙。唐代浪漫主义诗人。
- 李白《静夜思》：床前明月光，疑是地上霜。举头望明月，低头思故乡。
- 李白《将进酒》：君不见，黄河之水天上来，奔流到海不复回。属豪放风格代表作。
- 李白《蜀道难》：蜀道之难，难于上青天。属乐府体裁。
- 杜甫：字子美，自号少陵野老，后世尊称诗圣。唐代现实主义诗人。
- 杜甫《春望》：国破山河在，城春草木深。创作背景为安史之乱。
- 杜甫《茅屋为秋风所破歌》：安得广厦千万间，大庇天下寒士俱欢颜。表达忧国忧民情怀。
